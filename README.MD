# MediaDownloader

Кроссплатформенный консольный загрузчик медиафайлов на Python (обертка над yt-dlp). Автоматически качает видео (до 1080p) или конвертирует аудио в MP3 (320 kbps). Работает на Windows, Linux и в Termux на Android.

## Функционал
* Автоматическое определение операционной системы и путей сохранения.
* Изменение папок назначения прямо из интерфейса программы.
* Умная загрузка плейлистов в отдельные папки с сохранением их названий.
* Локальный скрытый архив (`.downloaded_archive.txt`) — повторно одни и те же файлы не скачиваются.
* Полная автономность: при сборке в `.exe` утилиты `yt-dlp` и `ffmpeg` зашиваются внутрь файла.

## Быстрый старт (из исходников)

1. Установите зависимости:
```bash
pip install -r requirements.txt
```
2. Запустите утилиту:
```bash
python downloader.py
```

*Примечание: Для работы исходного кода в системе должны быть установлены утилиты `yt-dlp` и `ffmpeg`.*

## Автоматическая сборка в .exe

Проект полностью настроен для сборки в облаке через **GitHub Actions**.

1. Сделайте `git push` проекта в свой репозиторий на GitHub.
2. Перейдите во вкладку **Actions** -> **Build Autonomic EXE**.
3. Дождитесь завершения и скачайте готовый автономный `MediaDownloader.exe` из раздела **Artifacts** внизу страницы.

*Собранный `.exe` файл весит около 80-90 МБ, так как содержит внутри себя все необходимые декодеры и работает на любом чистом ПК без установки Python и сторонних программ.*
